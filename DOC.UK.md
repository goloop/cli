## Дизайн

Інструмент - маленький диспетчер поверх `os.Args[1]`: одна субкоманда на
верхньорівневий аргумент, прапорці кожної команди парсяться інлайн. Без
сторонніх залежностей і прихованого стану. Він оркеструє інструментарій,
запускаючи наявні у вас інструменти; ніколи не комітить, не пушить і не
деплоїть.

## new

```text
goloop new <name> [--module path] [--dir path] [--force]
```

Створює мінімальний goloop-first сервіс:

| Файл | Призначення |
|------|-------------|
| `main.go` | сервіс із `run()` на базі `goloop/app` |
| `go.mod` | модуль із `--module` (дефолт `github.com/example/<name>`) |
| `.env` | стартова конфігурація |
| `.gitignore` | ігнор build-артефактів |
| `README.md` | як запускати |

Ім'я має відповідати `^[a-z][a-z0-9]*(-[a-z0-9]+)*$` і не бути зарезервованим
словом. `--dir` не має виходити вище робочої теки (без сегмента `..`). Без
`--force` наявну цільову теку не чіпає.

## check

```text
goloop check [dir] [--all]
```

Обходить `dir` (дефолт `.`) і повідомляє кожен рядок зі слідом ШІ-асистента,
пропускаючи `.git`, `node_modules`, `vendor` і `dist`. Повертає `0` при чистоті
й `1` при знахідці, тож вписується в CI, щоб тримати product-репозиторій без
слідів асистента. Файл, що виглядає бінарним (NUL-байт біля початку), за
замовчуванням пропускається, бо скомпільований артефакт чи зображення - не
джерело; `--all` сканує кожен файл fail-closed. Файл, який не вдалося прочитати
чи повністю просканувати, повідомляється, а не пропускається тихо.

## doctor

```text
goloop doctor
```

Перевіряє `go` і `git` (обов'язкові) та `docker` і `node` (опційні), друкуючи
шлях кожного інструмента або примітку про відсутність. Ненульовий код, коли
обов'язкового інструмента немає.

## status

```text
goloop status
```

Читає `go.mod` у поточній теці й друкує шлях модуля, версію Go і потрібні
залежності `github.com/goloop/*`. Розуміє обидві форми - однорядкову
(`require path v1`) і блокову (`require ( ... )`) - та ігнорує директиви
`replace` (вони перенаправляють залежність, а не оголошують її).

## version

```text
goloop version
```

Друкує версію CLI і платформу. Перевизначте версію під час збірки через
`-ldflags "-X main.Version=v1.2.3"`.

## Межі

MVP - це `new`, `check`, `doctor`, `status` і `version`. Мульти-репо топології,
deploy-скафолдинг і container smoke свідомо поза першою версією.

## Реліз v1.0.0

check повертає помилку обходу відсутнього або недоступного каталогу. Новий сервіс використовує app v1.0.0. Реліз v1 зберігає поточний import path і публічний API. Майбутні несумісні зміни потребуватимуть нової головної версії.
